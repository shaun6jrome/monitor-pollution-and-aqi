    • 2. Abstract

    Continuous Ambient Air Quality Monitoring Stations (CAAQMS) provide high-precision physical concentration measurements but lack the contextual intelligence required to identify the human and industrial activities driving pollution episodes. Conversely, global news feeds report environmental incidents in real time, yet naive text analysis suffers from severe syndication overcounting, geographic conflation, and lack of evidentiary provenance.

    This project implements an end-to-end Data Science Ecosystem that:

  • Ingests real-time environmental news via the GDELT DOC 2.0 API with SHA-256 deduplication and local disk caching.
  • Cleans, normalizes, and classifies unstructured text using a supervised TF-IDF + Logistic Regression baseline and an environmental entity extraction gazetteer.
  • Implements a multi-criteria event discovery engine combining semantic cosine embeddings, geographic boundary verification, a 72-hour temporal event window, and wire syndication auditing to discover distinct real-world incidents.
  • Conducts rigorous chronological time-series regression modeling on the 9,358-observation historical UCI Air Quality multisensor dataset, comparing Linear Regression, Random Forest, and XGBoost with zero temporal lookahead data leakage.
  • Deploys an interactive Streamlit environmental intelligence dashboard with verifiable data provenance, auditable input validation, and transparent limitation reporting.

    • 3. Problem Statement

    Existing environmental monitoring networks face two fundamental disconnects:

  • **The Context Gap:** Physical sensors report concentration spikes (e.g. $450\ \mu g/m^3$ of PM2.5) without causal explanations (e.g. an unpermitted factory boiler release, open municipal waste burning, or crop residue incineration).
  • **The Unstructured Information Redundancy Gap:** Naive aggregation of news articles treats every syndicated wire story (e.g. from PTI or ANI) as a distinct pollution event, inflating incident counts by over 100%. Furthermore, purely semantic grouping collapses distinct episodes across distant cities or weeks apart.

    • The objective is to design, implement, and validate an automated data pipeline that bridges this divide by discovering distinct, deduplicated pollution events from unstructured news while maintaining a rigorous predictive modeling foundation.

    4. Motivation and Scope

  • **Motivation:** Regulators and environmental policy bodies need rapid, evidence-grounded incident awareness to dispatch field inspectors and corroborate public grievances without being misled by artificial media duplication.
  • **Scope Boundaries:** The system integrates three independent data streams: GDELT unstructured news (contemporary incident discovery), CPCB official station observations (government ground truth), and the UCI historical dataset (multisensor regression benchmarking). The project strictly avoids scientifically fraudulent claims of cross-source causality between non-aligned historical sensor data and contemporary news.

    • 5. Objectives

  • Develop a fault-tolerant ingestion connector for the GDELT DOC 2.0 API with deterministic caching, rate-limit resilience, and respectful content extraction.
  • Implement a complete NLP pipeline for Unicode normalization, boilerplate removal, pollution relevance classification, and entity extraction.
  • Engineer a multi-criteria event discovery and deduplication engine combining semantic embeddings, geographic constraints, 72-hour temporal windows, and wire syndication auditing.
  • Establish an empirical machine learning benchmark comparing Linear Regression, Random Forest, and XGBoost on chronological splits of the UCI dataset.
  • Build an interactive environmental intelligence dashboard adhering to a professional graphite/charcoal design without decorative filler or fabricated metrics.

    7. Proposed Methodology

    The platform resolves these limitations through a four-stage pipeline:

  • **Data Ingestion & Persistence:** Bounded GDELT queries with SHA-256 URL hashing, SQLite WAL-mode transactional storage, and local JSON caching.
  • **Text Normalization & Classification:** NFKC Unicode standardization, URL/boilerplate filtering, and supervised TF-IDF + Logistic Regression classification.
  • **Multi-Criteria Event Discovery:** Pairwise candidate matching enforcing semantic threshold ($\ge 0.68$), geographic compatibility, 72-hour temporal proximity, and source category alignment.
  • **Leakage-Free Forecasting:** Chronological 80/20 train/test split, cyclical temporal encodings, historical lag features, and training-only median imputation.

    9. Data Source Descriptions

    9.1 GDELT DOC 2.0 API (Unstructured News Stream)

  • Endpoint: `https://api.gdeltproject.org/api/v2/doc/doc`
  • Output Format: JSON (`mode=ArtList`, `format=json`, `sort=DateDesc`).
  • Parameters: Configurable queries (`air pollution`, `industrial emissions`, `crop burning`, `factory smoke`).
  • Role: Real-time and near-real-time environmental incident discovery.

    • 9.2 UCI Machine Learning Repository: Air Quality Dataset

  • Reference: De Vito et al. (2008), University of California Irvine ML Repository (ID: 360).
  • Coverage: 9,358 hourly observations from an Italian urban roadside monitoring station (March 2004 – April 2005).
  • Fields: True chemical analyzer concentrations (`CO(GT)`, `NMHC(GT)`, `C6H6(GT)`, `NOx(GT)`, `NO2(GT)`) and 5 metal oxide chemical sensors (`PT08.S1` through `PT08.S5`), Temperature, Relative Humidity, and Absolute Humidity.
  • Missingness Sentinel: `-200` converted to `NaN`.

    • 9.3 Central Pollution Control Board (CPCB) / data.gov.in

  • Access: Official Indian Real-Time National Air Quality Index API.
  • Role: Official ground truth ambient station measurements.

    • 10. Unstructured-Data Processing Pipeline

  • **Normalization (`src/preprocessing/text_cleaner.py`):** Converts Unicode to standard NFKC, normalizes typographic quotes/dashes, strips news syndication disclaimers, and removes web URLs while strictly preserving chemical symbols (`PM2.5`, `PM10`, `NO2`, `SO2`, `CO`).
  • **Relevance Classifier (`src/preprocessing/event_classifier.py`):** Fits TF-IDF on a transparent domain corpus with Logistic Regression ($C=1.0$). Classifies articles into 1 (pollution), 0 (not pollution), or -1 (uncertain).
  • **Entity Extraction (`src/preprocessing/location_extractor.py`):** Uses an environmental gazetteer covering 30+ major monitoring hubs, chemical pollutant regexes, and 8 emission source categories with exact character spans.

    11.2 Provenance and Syndication Auditing

  • **Wire Syndication:** Articles published across separate domains with text similarity $\ge 0.85$ or shared agency attribution tags (PTI, ANI) are flagged as syndicated clones, preventing duplicate event creation.
  • **Evidence Quality Scoring:** Calibrates confidence from $0.50$ (single-source report) to $0.90$ (multi-domain independent reporting).

    • 12. Machine Learning Algorithms

  • **Linear Regression (Baseline):** Parametric ordinary least squares regression with standard feature normalization.
  • **Random Forest Regressor:** Bagging ensemble of 100 decision trees (max depth 12, min samples split 4) capturing non-linear sensor cross-sensitivities.
  • **XGBoost Regressor:** Gradient boosted regression trees optimizing mean squared error (100 estimators, learning rate 0.08, max depth 5, subsample 0.85).

    • 13. Feature Engineering and Leakage Prevention

  • **Temporal Cyclical Encodings:** 24-hour diurnal ($\sin(2\pi h/24)$, $\cos(2\pi h/24)$) and 12-month seasonal cycles ($\sin(2\pi m/12)$, $\cos(2\pi m/12)$).
  • **Historical Lags:** Target lags at $t-1, t-2, t-3, t-24$ without lookahead.
  • **Rolling Window Aggregations:** 6-hour rolling mean and standard deviation computed strictly on past observations (`closed='left'`).
  • **Leakage-Free Imputation:** Feature medians calculated strictly on training rows ($80\%$) and applied to test rows ($20\%$).

    • 14. Experimental Design

  • **Chronological Split:** Chronological 80% train / 20% test split.
  • **Evaluation Criteria:**
    • y_i - \hat{y}_i
  • Root Mean Squared Error (RMSE): $\sqrt{\frac{1}{n} \sum (y_i - \hat{y}_i)^2}$
  • Coefficient of Determination ($R^2$): $1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$

    • 18. Results and Discussion

  • **Deduplication Effectiveness:** Multi-criteria clustering successfully eliminates syndication inflation while preventing false merges across distant regions.
  • **Predictive Capability:** Historical sensor modeling confirms that non-linear tree ensembles effectively calibrate solid-state chemical sensors against true reference analyzer concentrations.
  • **Scientific Separation:** Maintaining strict boundaries between Italian historical sensor data and contemporary Indian news prevents data contamination and preserves academic integrity.

    • 19. Limitations

  • **Non-Alignment Between Datasets:** The 2004–2005 Italian sensor dataset and modern GDELT news cannot be joined for direct cross-source training without scientific invalidity.
  • **Media Reporting Bias:** News coverage disproportionately favors major capital cities over rural areas.
  • **Textual Location Resolution:** Geographic locations remain textual entities unless an official geocoding service is configured.
